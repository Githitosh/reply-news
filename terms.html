  • 本規約に同意し、適用される法令のもとで本サービスを利用できる方が利用できます。
  • 会社などの団体のために利用する場合、その団体に代わって本規約に同意する権限があるものとします。

2. プライバシー

  • 本サービスに会員登録はありません。運営者は、利用者の個人情報を集めたり保存したりしません。アクセス解析や広告の仕組みも使っていません。
  • 本サービスのページがつなぐ外部のサービスは、Xが公式に公開している埋め込み用API（publish.x.com）だけです。利用者が投稿のリンクを貼り付けたときに、その投稿の文を読むために使います。その際、IPアドレスなどの通信情報がXに送られ、Xの規約とプライバシーポリシーに従って扱われます。リンクを貼り付けなければ、つなぎません。
  • その日の会話のデータは、運営者のGitHub（https://github.com/Githitosh/githito.xapi ）に置いたファイルから読み込みます。それ以外の他社のサービス（API）にはつなぎません。文字（フォント）、背景の写真、音楽は、本サービスのサイト内のファイルから読み込みます。
  • 読み込んだその日の会話と、利用者が貼り付けた投稿・リプライ、設定は、次に開いたときにすぐ表示できるよう、利用者のブラウザの中に保存されます。運営者には送られません。
  • 本サービスは GitHub Pages で公開しています。ページの配信にあたり、GitHub が通信情報を扱います。

3. 表示される内容

  • 動画に表示されるのは、次の2つです。(1) 運営者のプログラムが1日3回（6時・12時・18時ごろ）集め、運営者のGitHub（githito.xapi）に保存した、その日の投稿とリプライ（保存したものがあるときだけ）。(2) 利用者が自分で貼り付けた投稿とリプライ。
  • (1) は、個人の投稿と、それに付いたリプライを組にしたものです。運営者のプログラムは、投稿を探すためだけに FxTwitter（api.fxtwitter.com）を使い、選んだ投稿とリプライの本文と投稿者を、X公式の埋め込みAPIで読み直して保存します。Xで表示されなくなった投稿や、本文が食い違う投稿は保存しません。利用者のブラウザが FxTwitter につながることはありません。
  • 企業・報道機関などの投稿は最初の投稿に選びません。暴力、性的な内容、重い話題、けんか腰の言葉、広告は選びません。自動で集めた会話は48時間、運営者が手で選んだ会話は14日で消します。ただし完全ではなく、不快なものが表示されることがあります。
  • ご自身の投稿を表示しないでほしい場合や、権利の侵害を見つけた場合は、下記のお問い合わせ先までお知らせください。確認のうえ対応します。

  • 投稿のリンクを貼り付けたときは、投稿者の名前とリンクを動画に表示します。文を貼り付けたときも、投稿のアドレスや「@名前」が含まれていれば表示します。
  • 何を貼り付けて動画にするかは利用者が決め、その内容について利用者が責任を負います。運営者は内容の正確さや適切さを保証しません。
  • 背景の写真と音楽は、パブリックドメインなど自由に使える素材を使い、出典を画面に表示しています。文字は Noto Serif JP、Noto Sans JP、Tinos（SIL Open Font License）を使っています。

4. 本サービスの利用

  • 本サービスは無料で利用できます。
  • 使い方：ページを開くと、その日の会話から自動で動画を作ります。ジャンルを押すとそのジャンルの会話で作り直し、入力欄に言葉を入れるとその言葉が入った会話を探します。最後まで流れると次の動画に進みます。自分で会話を足すときは、投稿とリプライのリンク（または文）を「投稿」「リプライ」に貼り付けて「動画に追加」を押します。1つの会話は、最初の言葉 → 投稿の全文 → リプライの全文 → 投稿とリプライ、の順に表示されます。リプライは、リンクなら1行に1つ、文なら空行で区切ると、複数入れられます。
  • ダウンロードした動画に含まれる投稿の権利は、投稿者にあります。動画を共有・公開するときは、法令、Xの利用規約、投稿者の権利を守ってください。その責任は利用者が負います。
